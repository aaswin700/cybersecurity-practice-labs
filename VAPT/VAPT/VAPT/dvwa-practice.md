# DVWA Vulnerability Practice

## About the Lab
For learning purposes, I practiced basic vulnerability testing using
Damn Vulnerable Web Application (DVWA) in a local lab environment.
The security level was kept low to understand the fundamentals.

## What I Tested
- Login functionality
- Input fields in forms
- URL parameters

## Observations
- Some input fields did not properly validate user input
- Basic SQL injection concepts were observed
- Reflected XSS behavior was understood

## Learning Outcome
This practice helped me understand how common web vulnerabilities occur
and why proper input validation and secure coding practices are important.
